# Field & Form

A small home-goods shop with an AI assistant for product search and customer support.

The catalog is six products (carafe, weekender, slippers, lamp, plates, merino throw). Shoppers can filter the floor by keyword, open a product, and ask the assistant about fit, price, shipping, returns, or a demo order.

## What the assistant does

Replies are generated by Grok (`grok-4.5` on the xAI API) from a server function. The prompt includes the catalog and shop policies, so answers stay on the products that exist.

Demo order numbers:

| Order | Status |
| --- | --- |
| FF-1042 | Shipped, tracking `1Z9FF204` |
| FF-1108 | Processing |
| FF-0981 | Delivered |

Try: “What do you have under $80?”, “How do returns work?”, or “Where is order FF-1042?”

The API key is read only on the server (`XAI_API_KEY`). It is never sent to the browser. If the key is missing, the chat shows that the assistant is unavailable. The catalog search still works.

## Stack

React 19, TanStack Start, Tailwind CSS v4. No accounts and no database. The catalog lives in `src/lib/catalog.ts`. Chat history stays in the page until reload.

## Run locally

```bash
npm install
export XAI_API_KEY=your_key   # optional, enables the assistant
npm run dev
```

## CI

GitHub Actions (`.github/workflows/ci.yml`) runs `npm ci`, typecheck, and a production build on every push to `main` and on pull requests. No API key is required for the workflow.

## Layout

- `src/components/shop-app.tsx` — storefront and chat panel
- `src/lib/catalog.ts` — products and policies
- `src/lib/chat.functions.ts` — server call to the xAI chat API
- `public/products/` — product photos
